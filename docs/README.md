# Матеріали звіту

Фінальний звіт до лабораторної роботи буде підготовлено українською мовою
відповідно до ДСТУ 3008:2015, бібліографічні посилання — відповідно до
ДСТУ 8302:2015, а параметри сторінки й тексту — за методичними вказівками
кафедри ПІ ХНУРЕ.

Планована структура звіту:

1. Титульний аркуш.
2. Мета роботи та індивідуальне завдання.
3. Опис структури програми й обраних типів даних.
4. Опис реалізації та ключові лістинги.
5. Результати виконання і статичного аналізу.
6. Висновки.
7. Перелік джерел посилання.
